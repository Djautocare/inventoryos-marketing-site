Using the output

Print at actual size (100% scale). Scan a sample label before you print a batch. Code 128 labels for internal use do not assign retail GTINs or EANs.

When to use the barcode generator

Use a Code 128 barcode when you need a scannable label for something inside your own business: a product you made, a bundle, a storage box or a shelf location. Code 128 accepts letters, numbers and common symbols, so you can encode the same reference you already use, such as a SKU or a location name.

If you sell through a retailer that asks for an EAN or UPC, you need a registered GTIN from GS1 instead. A Code 128 label made here is for internal stock control, not for supermarket checkouts.

Worked example

  1. Enter the value SHELF-A1 and the label text Shelf A1 · candles.
  2. Choose 50 × 25 mm to match a small direct thermal label roll.
  3. Generate the barcode, then download the SVG or print it at 100% scale.
  4. Scan the printed sample with your phone or USB scanner before printing a full set.

Common questions

Can I use these barcodes on retail products?

Only for your own internal use. Retailers that scan products at a checkout usually require a GS1-registered GTIN (EAN-13 or UPC), which this tool does not assign.

What should the barcode value be?

A short, unique reference you already use, such as a SKU or a location name. Keep it short: shorter values print wider bars, which scan more reliably on small labels.

Which label size should I choose?

Pick the size that matches your label roll: 50 × 25 mm or 76 × 38 mm for products and shelves, or 100 × 150 mm (4 × 6 inch) for large box and location labels.
