# InventoryOS marketing site — project memory

## Working rules
- Never commit, push, merge or deploy without the owner's explicit approval. Work only on the assigned `claude/*` branch; `main` auto-publishes to production (Cloudflare Pages serves committed files, no build step).
- Preview first: prototypes live outside the repo (scratchpad) and are shown as private Artifacts.
- One development stage at a time. Replies: short (3–5 sentences), report only changes, test results, blockers, next steps. No repeated audits, no full-file output unless asked.
- Keep every piece of existing copy, SEO content, links and functionality. Reuse existing components and assets.
- Use fictional business/order/customer data only. Only demonstrate features that exist; label planned features as planned.
- Update this file when an important decision changes.

## Architecture
- React 19 + esbuild, pre-rendered to static HTML by `scripts/build.mjs` (`npm run build`), output committed: `index.html` (resellers), `manufacturing.html`, `retail.html`, `assets/marketing.js|css`, `assets/marketing/entry-*.js`.
- Source: `src/App.jsx` (all homepage sections), `src/data/content.js` (modes resellers/manufacturing/retail, plans, FAQs, `signup`/`login` URLs), `src/motion.js` (GSAP 3.15 ScrollTrigger + Lenis, desktop fine-pointer only, reduced-motion off), `src/components/` (React Bits SpotlightCard, AnimatedContent).
- Homepage order: Header → ModeNav → Hero → DemoIntro (`<inventoryos-demo>` player, resellers only, `assets/demo/`) → Tour → EmailFeature → Features → Audiences → Shop band → Marketplace/Storefront → PracticalGuides → Steps → Pricing → FAQ → FinalCta → Footer.
- Other pages: features, tour, tools (`/tools`), shop, marketplace, guides, policies (`scripts/build-*.mjs`). Tests: `npm test` (`tests/*.test.mjs`). Preview copy: `node scripts/prepare-preview.mjs` → `dist/`.
- `_headers` CSP: `script-src 'self'` (no CDNs; bundle libraries locally). Decoders using WASM would need `'wasm-unsafe-eval'`.
- Real screens: `assets/workflow/*.webp` (stock-overview, sales-till, sale-receipt, label-preview, dispatch-centre, reorder, production, recipes, materials, invoice-inbox), `assets/demo/screens/*.webp`.
- URLs: app `https://app.inventoryos.co.uk/login.html` (`?view=register` signup), guest demo `/try-inventoryos.html`.

## Branding
- Live site: Manrope (local font), paper `#f8f7f4`, ink `#222124`, purple `#7344e7`; dark default with appearance toggle; 8 languages.
- Owner's Design System artifact (target direction, used in prototypes): teal accent `#0d8f7e` with dark text `#0b1412`, Bricolage Grotesque + Inter, 18px outer radius, single-stroke 24px icons (1.75 stroke), tabular numbers, theme follows device, UK English, no emoji/filler badges. Headline: "Follow every item from shelf to dispatch." Pro is the featured plan. Final palette for the live merge still to confirm.

## Real product features (safe to show)
Stock and locations/consolidated picking, Retail till (PWA) and receipts, online orders, packing queue, shipping-label upload and cropping to 4×6, Dispatch Centre and label printing, manufacturing recipes/materials/production batches, SKUs and barcode labels, reorders, invoice inbox, reports/overview dashboard. Plans: Intro £0, Premium £7.99/mo, Pro £19.99/mo (one store included, extra stores £10/mo).
